# 🤖 Cloudflare Workers Monitor Bot

یه ربات تلگرام برای مانیتورینگ Cloudflare Workers

---

## ✨ امکانات

- 📊 مشاهده آمار هر اکانت به صورت جداگانه
- 🔀 مقایسه مصرف روزانه همه اکانت‌ها
- 📅 گزارش هفتگی (هر شنبه ساعت ۹ صبح)
- 🌅 گزارش دیروز (هر روز ساعت ۸:۳۰ صبح)
- 🏅 امتیاز ماهانه با درجه‌بندی A تا D
- 🚨 هشدار خودکار وقتی نرخ خطا از ۴۰٪ بیشتر شد
- 🚨 هشدار وقتی ریکوست به ۱۰۰,۰۰۰ رسید
- 🔕 دکمه سکوت ۲ ساعته برای خاموش کردن هشدارها
- 💰 محاسبه تخمینی هزینه
- 📈 مقایسه با دیروز (↑ ↓)
- 🔒 دسترسی فقط برای صاحب ربات
- ♾️ پشتیبانی از تعداد نامحدود اکانت

---

## 🛠 نصب و راه‌اندازی

### ۱. کلون کردن پروژه
```bash
git clone https://github.com/your-username/your-repo.git
cd your-repo
```

### ۲. نصب وابستگی‌ها
```bash
pip install python-telegram-bot apscheduler requests
```

### ۳. تنظیم متغیرهای محیطی

| متغیر | توضیح |
|-------|-------|
| `BOT_TOKEN` | توکن ربات تلگرام از @BotFather |
| `CHAT_ID` | آیدی عددی تلگرام شما از @userinfobot |
| `ACCOUNT_ID` | آیدی اکانت اول Cloudflare |
| `CLOUDFLARE_TOKEN` | توکن API اکانت اول |
| `ACCOUNT_ID_2` | آیدی اکانت دوم |
| `CLOUDFLARE_TOKEN_2` | توکن اکانت دوم |
| `ACCOUNT_ID_3` | آیدی اکانت سوم |
| `CLOUDFLARE_TOKEN_3` | توکن اکانت سوم |
| `...` | هر تعداد اکانت که بخوای |

> ربات خودکار همه اکانت‌ها رو به ترتیب از متغیرهای محیطی میخونه.
> هر وقت `ACCOUNT_ID_N` و `CLOUDFLARE_TOKEN_N` اضافه کنی، بدون تغییر کد توی ربات ظاهر میشه.

## 🔑 گرفتن توکن و آیدی Cloudflare

**Account ID:**
- وارد [dash.cloudflare.com](https://dash.cloudflare.com) بشو
- سمت راست صفحه زیر **Account ID** هست

**API Token:**
- برو **My Profile → API Tokens → Create Token**
- از تمپلیت **Edit Cloudflare Workers** استفاده کن

## 📱 دستورات ربات

| دکمه | عملکرد |
|------|--------|
| 📊 اکانت N | آمار ۲۴ ساعته هر اکانت |
| 🔀 مقایسه | مقایسه مصرف امروز همه اکانت‌ها |
| 📅 گزارش هفتگی | آمار ۷ روز گذشته |
| 🌅 گزارش دیروز | آمار دیروز |
| 🏅 امتیاز ماهانه | کارنامه ۳۰ روز گذشته |
| 🔕 سکوت | خاموش کردن هشدارها برای ۲ ساعت |
